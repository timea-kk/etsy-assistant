# Pinterest pin template

Each pin needs all of these fields.

- Title: under 100 characters. Lead with the main search phrase.
- Description: 200 to 300 characters. Count it. Two or three keywords, a clear benefit, and "hand-drawn, no AI" when true. No hashtags.
- Text overlay: 4 to 8 words, in the top half of the image so it shows on mobile.
- Image: 1000 x 1500 px, 2:3, JPG or PNG, under 5 MB. Say if a source image needs cropping or padding.
- Alt text: one sentence describing the image. Include a keyword where it fits naturally.
- Board: one board, from the existing board list.
- Tagged topics: up to 10, chosen from Pinterest's list in the pin editor. Suggest options; Timea selects.
- Link: the clean listing URL only, no tracking parameters.

## Pin sets
- One pin per main image: product showcase, what's included, a detail or in-use image, and a seasonal or mockup image.
- Vary titles so pins don't compete with each other.
- Use the same board and similar tagged topics for pins from one listing.

## Check before output
- Title under 100 characters
- Description 200 to 300 characters
- Overlay 4 to 8 words
- No hashtags
- Link is clean
